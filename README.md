# Rust WASM loading pages from API call
Quickly pulled together a prototype of a site that uses Rust to perform an API call (to TheNewsApi) and then creates pages.

Using AstroJs and React for dynamic islands.

## Set up
- Get API Key from [thenewsapi](URL "https://www.thenewsapi.com/") and add to .env
- ``docker-compose up``

- visit: [localhost:4321](URL "localhost:4321")
